# Algorithmic Designs & Strategies

This directory houses detailed algorithmic specifications and design documents for solver routines:

- **Simplex Method**:
  - Revised Primal Simplex and Dual Simplex algorithms.
  - Basis update techniques: Forrest-Tomlin updates, product form of the inverse (PFI).
  - Pricing strategies: Dantzig rule, Devex pricing, Steepest-Edge pricing.
- **Interior Point Methods (IPM)**:
  - Primal-Dual Path-Following methods.
  - Mehrotra Predictor-Corrector step computation.
  - Normal equations vs. Augmented system solves.
- **Mixed-Integer Branch & Bound**:
  - Tree exploration policies (Best-bound, Depth-first).
  - Branching strategies (Most infeasible, Pseudocost branching, Strong branching).
  - Cut generation routines (Gomory cuts, MIR cuts).
