# Benchmark Automation Scripts (`benchmarks/scripts/`)

## Purpose
Houses automated execution scripts, data collectors, and reporting tools to orchestrate standardized solver benchmark runs.

## Planned Capabilities
- Automated execution of instance batches with deterministic timeouts and resource limits.
- Parsing solver output logs to extract iteration counts, solve times, objective values, and residual norms.
- Generation of Dolan-Moré performance profile curves and shifted geometric mean summaries.
