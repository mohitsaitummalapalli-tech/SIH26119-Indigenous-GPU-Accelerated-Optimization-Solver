# Benchmark Problem Instances (`benchmarks/instances/`)

## Purpose
Storage location for public standard benchmark instances used for solver validation and performance comparisons.

## Planned Collections
- **Netlib LP**: Classic standard linear programming test set.
- **Mittelmann Benchmarks**: Industry-recognized test instances for simplex, interior point, and QP solvers.
- **MIPLIB 2017**: Benchmark subset for mixed-integer programming evaluation.
